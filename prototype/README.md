# PRO KAYAK FISHING — Windy Style Prototype
نسخة مستقلة داخل المستودع لا تستبدل المشروع القديم.

## مدمج الآن
- خريطة Leaflet + Satellite
- GPS واختيار نقطة على الخريطة
- Open-Meteo Weather + Marine
- رياح متحركة + Timeline
- Waves / SST / Currents للنقطة
- Fishing Score أولي
- واجهة طبقات وأساس Fishing Planner

## المرحلة التالية
Bathymetry tiles، طبقات مكانية كاملة للرياح/الأمواج/التيارات، المد والجزر، Solunar، مناطق تونس، أنواع الأسماك، حفظ سحابي، Offline، ثم APK.

> هذه نسخة Prototype وليست تطبيق ملاحة أو ضمان سلامة بحرية.
